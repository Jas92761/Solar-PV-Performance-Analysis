# Solar Photovoltaic Systems Performance Analysis

Computational simulation model developed in **Scilab** to evaluate the electrical performance and energy conversion efficiency of solar photovoltaic (PV) architectures. 

This project was developed and published as an official case study via the **IIT Bombay FOSSEE Scilab** platform.

## Overview
- **Objective:** Model I–V and P–V characteristics of solar PV modules under varying operating conditions.
- **Key Analysis:** Isolates and evaluates **5 key parameters** governing energy conversion efficiency (including solar irradiance, cell temperature, series resistance, shunt resistance, and diode ideality factor).
- **Publication:** [Official FOSSEE Scilab Case Study](https://scilab.in/case-study-project/case-study-run/87)

## How to Run
1. Install [Scilab](https://www.scilab.org/) on your system.
2. Clone or download this repository.
3. Open the `.sce` / `.sci` script files in the Scilab console or SciNotes editor and execute the simulation.
